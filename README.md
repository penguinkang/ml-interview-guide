# interview Senior Staff ML Interview Guide

Personal bilingual interview study guide. This is not an official interview interview bank.

Live: https://penguinkang.github.io/ml-interview-guide/

GitHub Actions builds the static version and deploys it to GitHub Pages on pushes to `main`.

Edit `outputs/ML-Interview-Study-Guide.html`; `scripts/build_pages.py` creates the online edition in `site/index.html`.

Online features: 50 questions, importance filters, dark mode, quizzes, browser-local progress and answer drafts, prepared solutions with Python highlighting.

Python execution and Ollama hints/grading require the separate local server and are disabled online. GitHub Actions deploys the static files; it does not run a persistent Python/Ollama server. Browser storage is device-specific, not synchronized.
